# Bayesian-VAR-Model-for-forecasting-indian-GDP-for-Q1-2026-27
Built Bayesian VAR model to forecast Q1 2026-27 GDP Growth Rate for Indian Economy using GDP Growth Rate, Inflation Rate, Money Supply, Index of Industrail Production and Oil Prices as Variables. I use Minessota Prior in this model. Forecasted Value for Q1 2026-27 GDP is 6.5%.
i have used Rstudio and R programming version 4.6 for this project.
To Run Project R file, load all libraries then press CTRL+Enter on all codes. output will be display on console if you are using Rstudio
